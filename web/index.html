APEX / MOTO FIELD LAB

一条能骑行、也能检查的信号链。

W / ↑ 加速，S / ↓ 刹车，A / D 或左右方向键转向。P 暂停，R 重开，L 开关远光灯，Q / E 控制转向灯。触屏可按住屏幕下方按键。

道路沿样条曲线生成，车辆采用公路相对坐标的街机驾驶：方向控制横向位置，镜头随公路与倾角变化。驶出沥青会减速，碰到护栏或路障罚时 3 秒，通过四个检查点后完成一圈。自动巡航可用于观看与信号演示，不计入手动最佳成绩。

山体、道路、树林、路障、摩托车、纹理和路牌由代码生成；发动机、风噪与提示音由 Web Audio 合成。3D 引擎为 Three.js（MIT），不使用外部模型、贴图或音频文件。

模拟 ECU → 三类 CAN 帧 → DBC 解码 → 信号质量 / 告警 → 仪表。左侧显示真实经过本项目解码器的帧与数值。故障可在右侧注入，600 ms 通信超时后仪表读数失效，3D 游戏仍可继续操控。

个人 Web 工程演示；合成 CAN/DBC、街机动力学，不是实车、Qt/QML 或车规测试。参考 Starter-Kit-Racing 的赛车模板组织思路；游戏资产与实现独立生成。Three.js 许可证。
